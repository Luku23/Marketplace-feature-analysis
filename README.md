# Marketplace Paid Promotion Feature Analysis

A small data analysis project focused on a marketplace paid promotion ("push-up") feature.

## Goal

The goal of the project was to explore the dataset, evaluate its quality, measure how frequently the paid promotion feature is used, and identify patterns that could help with pricing and business decisions.

## Main overview

- Evaluated data quality and dataset granularity
- Created a push-up rate metric
- Compared performance across categories and subcategories
- Visualized push-up usage, listing volume, and revenue
- Analyzed the relationship between average listing price and push-up usage
- Proposed an A/B test for evaluating a possible price change

## Key findings

- Overall push-up rate was approximately 3.21%
- Push-up usage varied significantly between subcategories
- Higher average listing prices were associated with higher push-up usage
- Large subcategories generated most of the absolute push-up revenue
- Pricing changes should be tested experimentally before being rolled out
